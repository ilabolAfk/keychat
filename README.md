# KeyChat 🔗

Локальный мессенджер на **PySide6** с SQLite-хранилищем, **шифрованием сообщений и файлов**, тёмной темой и оранжевыми акцентами.

## Возможности

- **Регистрация и вход по паролю**: пароль хранится в виде salted-хеша (scrypt), не в открытом виде
- Список чатов с аватарами, последним сообщением и временем
- Окно переписки с «пузырями» сообщений (свои — акцентного, чужие — тёмного цвета)
- **Шифрование**: текст сообщений и файлы шифруются (Fernet/AES) на лету, ключ хранится в `keychat.db.key` рядом с базой (не хардкодится)
- **Пересылка файлов**: кнопка-скрепка, файл шифруется и сохраняется в папке `keychat_files`, клик по файлу-пузырю — скачивание с расшифровкой
- **Стикеры**: папка `stickers/` рядом с проектом читается автоматически (без хардкода путей), кнопка-смайл открывает панель выбора превью, клик отправляет стикер
- **Кастомизация**: настройки смены темы (тёмная/светлая) и акцентного цвета с живым предпросмотром, смена пароля
- **Задел под звонки**: кнопка вызова в шапке чата и каркас `CallDialog` (заглушка под будущую передачу голоса/видео)
- Настройки: смена username, контакт, смена пароля, сброс всей истории
- Интерфейс: эмодзи заменены на векторные иконки QtAwesome
- История сохраняется в SQLite на диске

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

Стикеры: положите PNG в `stickers/` в корне проекта — они появятся в панели выбора.

## Структура

```
main.py                   — точка входа, инициализация БД + шифрования
keychat/
  database.py             — SQLite: пользователи, чаты, сообщения (типы text/sticker/file), настройки
  security.py             — шифрование Fernet + salted-хеш паролей (scrypt)
  login.py                — вход/регистрация по username и паролю
  main_window.py          — главное окно: сайдбар, чаты, переписка, стикеры, файлы, звонок
  settings_dialog.py      — настройки: тема, акцент, пароль, профиль
  calls.py                — каркас звонка (CallDialog, заглушка)
  stickers.py             — чтение папки стикеров и панель выбора
  theme.py                — динамическая палитра и генерация QSS под акцент/тему
  widgets.py              — аватар
```

База (`keychat.db`), ключ (`keychat.db.key`) и папка вложений создаются автоматически рядом с пакетом.
